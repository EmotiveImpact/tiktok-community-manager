# Aperture Studio demo asset

`aperture-studio-host.png` is an original image generated on 11 October 2026 with
the Image Gen tool: a fictional studio presenter, microphone and laptop in a warm,
dark room with plants, books and practical lighting. Dimensions: 1672 × 941 pixels.
It follows the selected Aperture Studio art direction. No real person's identity
or actual LIVE recording is asserted.

The image was used only in an isolated synthetic demonstration: a generated still
plus tone, recorded through FFmpeg into real retained segments. Caption text was
inserted as labelled fixture data. It is not imported into the application as a
default video, thumbnail or replacement for unavailable recording data.

Actual app screenshots and the media disclosure are in [Aperture Studio](../APERTURE_STUDIO.md).
The source image is kept here for reproducibility; runtime media and databases
remain outside Git. The self-hosted Inter font has separate source and SIL Open
Font License records in `src/assets/fonts/`.
