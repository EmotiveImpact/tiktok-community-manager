Design rules applied

1. One button system — every interactive element is 28px tall, 7px radius, same font size (12px). Variants: .btn (ghost), .btn-secondary (outline), .btn-primary (gradient), .btn-active (pink-tinted).

2. Status as a colored dot + label — same shape and size in all 4 states. Idle/Connecting/Live/Error use the same component, just different colors.

3. Connected state hides the input — replaces it with a host chip (avatar + nickname + uptime). Less clutter, clear context.

4. Logical grouping — left: connection state. Right: actions. Divider before Tools ▾ so utility lives together.

5. Badges live inside buttons — same height as button, pink fill matches brand. Used for tracked count and active alert count.

6. Watch goes btn-active when stream is open — clear visual indicator without a toggle ON/OFF state.

7. Stats strip only when connected — disappears in idle. No empty placeholder = less visual noise.
