How they differ

Option B (Electron, Native Feel)

✓ Window vibrancy — real macOS blur shows through

✓ SF Pro at native sizes (12/13/14px)

✓ 0.5px separators instead of 1px borders

✓ 22px control height matches macOS HIG

✓ System accent blue (#007aff) for primary actions

✓ 5–6px corners instead of 8px

✓ Sidebar pattern with sectioned sources list

✗ Still rendered by Chromium — no real NSView controls

✗ Animations don't match native easing curves perfectly

Option C (True Native, SwiftUI)

✓ Real NSToolbar with SF Symbols (genuine system icons)

✓ Real NSSplitView sidebar (collapses, system gestures)

✓ Real NSTableView rows with native selection animation

✓ Native menu bar, shortcuts, services for free

✓ 50% smaller binary, no Chromium runtime

✓ Spotlight, share sheet, drag/drop all work natively

✓ Light/dark mode tracks system instantly

✗ Need to rewrite TikTok connection layer in Swift (or bridge via XPC to a Node helper)

✗ ~2-4 weeks of work for feature parity
